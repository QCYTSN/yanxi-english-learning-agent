# Scoring integrity

All numeric Writing and Speaking estimates use official IELTS criteria. Skills
may choose a teaching method, but they must not create substitute rubrics,
automatic caps, or an extra scoring criterion.

## Official sources

- Writing format and assessment:
  https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-writing
- Writing Band Descriptors:
  https://ielts.org/cdn/ielts-guides/ielts-writing-band-descriptors.pdf
- Writing Key Assessment Criteria:
  https://ielts.org/cdn/ielts-guides/ielts-writing-key-assessment-criteria.pdf
- Speaking format and assessment:
  https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-speaking
- Speaking Band Descriptors:
  https://ielts.org/cdn/ielts-guides/ielts-speaking-band-descriptors.pdf

## Writing

- Academic Task 1 uses Task Achievement; Task 2 uses Task Response.
- Coherence and Cohesion, Lexical Resource, and Grammatical Range and Accuracy
  apply to both tasks.
- The four criteria within one task have equal weight.
- Task 2 contributes twice as much as Task 1 to a complete Writing test result.
- A numeric task estimate requires the official descriptor source, evidence,
  confidence, task type, scored version and all four criterion scores.

## Speaking

- The official criteria are Fluency and Coherence, Lexical Resource,
  Grammatical Range and Accuracy, and Pronunciation, with equal weight.
- Content is not a fifth criterion. Relevance, development and logical sequence
  can affect FC; appropriacy and flexibility can affect LR.
- Transcript-only review may produce a partial FC/LR/GRA profile. It must not
  produce Pronunciation or a full Speaking overall.
- Voice/Live provisional scores remain source-model evidence. The system result
  is produced independently by the local Agent against the official descriptors.

## Listening and Reading

- Accuracy requires a verified answer key and explicit accepted-answer rules.
- An unanswered or unverified item is not silently counted as wrong.
- Do not invent a raw-score-to-band conversion. Store the raw score and record
  a band only when the conversion source used for that practice is known.

## Labels

- `official_result`: authorised IELTS result supplied by the user
- `answer_key_estimate`: result derived from a verified practice key
- `ai_training_estimate`: local official-rubric estimate with confidence
- `partial_profile`: incomplete criterion evidence; no complete overall
- `unspecified`: preserved legacy record with unknown provenance
