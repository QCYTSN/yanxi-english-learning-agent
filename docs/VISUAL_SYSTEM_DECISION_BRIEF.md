# IELTS Study Desk 最终视觉决策简报

状态：等待产品负责人确认。本文只冻结决策题，不在工程批次中偷偷锁定最终视觉。

## 已经确定、不需要再讨论的部分

- 学习页面只呈现学习任务；模型、数据、外部 Agent 和诊断留在设置；
- 主导航保持 Today、Practice、Library、Progress，Settings 独立放置；
- 对话是 IELTS 教师入口，不是通用聊天广场；
- 桌面优先，同时保证窄屏、200% 缩放、键盘和 reduced-motion 可用；
- 不照搬 DeepTutor 的品牌，但学习其留白、信息节奏、排版尺度和低干扰交互；
- 最终系统必须覆盖首页、对话、四科工作区、反馈、资料库、进步和设置，不能只美化首页。

## 推荐方向：学术编辑台

建议以“安静、可信、有求知欲的 IELTS 学术编辑台”为主方向：

- 大标题可使用有书卷感的中文衬线字体，正文和控件使用高可读无衬线字体；
- 背景接近自然纸张，正文使用深墨色，强调色只承担当前状态和关键行动；
- 依靠字号、行高、栏宽和留白建立层级，减少卡片套卡片、粗边框和无意义标签；
- 阅读、精读和长回复优先保证舒适行长；作文与题目工作区优先保证稳定双栏；
- 图标保持同一线性家族，不使用装饰性 3D 插画抢夺学习注意力；
- 动效只解释状态变化，持续时间短，并完整尊重 reduced-motion。

这最接近用户已经认可的第三版 Study Desk 信息架构，也能吸收 DeepTutor 的舒适感，而不会变成它的仿制品。

## 需要确认的五个决定

开始最终视觉实现前，只需要确认以下选择：

1. **整体气质**：A 学术编辑台（推荐）；B 更正式的考试机构；C 更轻盈的现代学习工具。
2. **标题字体**：A 中文衬线标题＋无衬线正文（推荐）；B 全无衬线；C 仅阅读长文使用衬线。
3. **主强调色**：A 深青绿（推荐，延续 Study Desk）；B IELTS 联想的克制酒红；C 冷静藏蓝。
4. **界面密度**：A 舒展但不空旷（推荐）；B 紧凑效率型；C 大留白沉浸型。
5. **深色模式**：A 最终视觉之后单独补（推荐）；B 与亮色同步设计。

如果没有额外意见，默认组合为：`A / A / A / A / A`。

## 最终视觉实施验收

- 建立颜色、字体、字号、行高、间距、圆角、边框、阴影和动效 Token；
- 用同一套 Token 完成全部核心页面，不允许页面各自发明样式；
- 在 1280、1440、1920 宽度和 125%/150%/200% 缩放下检查；
- 键盘焦点、错误、加载、空状态、断线、长文本和超长标题均有完整状态；
- 真实中文、英文原文、题目、长作文和长 Agent 回复都经过排版走查；
- 最后再做截图级视觉对比与交互验收，不以单张首页效果图代替产品验收。
