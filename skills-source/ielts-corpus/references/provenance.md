# Provenance rules

Allowed source types:

- `project_original`: created for this project and covered by its data licence;
- `official_external`: official source referenced externally, not automatically
redistributable;
- `licensed_private`: material the user legally obtained for private use;
- `seasonal_reported`: unofficial recollection with uncertainty;
- `personal`: learner-created content;
- `synthetic`: AI/human-generated practice material, never an authentic test.

Every indexed question should retain:

- corpus ID;
- source type;
- authenticity label;
- review status;
- content hash;
- optional passage and evidence location.

Do not infer authenticity from a filename or website popularity.
