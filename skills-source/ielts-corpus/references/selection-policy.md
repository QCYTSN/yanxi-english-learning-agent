# Question selection policy

Prefer questions that satisfy, in order:

1. requested module and task;
2. current weak question type or topic;
3. verified or reviewed source metadata;
4. not completed recently;
5. appropriate difficulty and available answer evidence.

For formal mock tests, preserve the original test grouping and timing. For
skill drills, individual indexed questions may be selected. Do not expose the
answer key before the learner commits an answer unless they explicitly request
post-practice review.
