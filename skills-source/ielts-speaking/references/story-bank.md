# Personal story bank

Store reusable experiences under `IELTS_HOME/story-bank/`.

A story is not a memorised answer. It is a collection of facts that can be
selected and reorganised for different prompts.

```yaml
story_id: university-ai-project
title: A difficult AI project
people:
  - teammate
places:
  - university laboratory
events:
  - identified a data problem
  - redesigned the workflow
feelings:
  - frustrated
  - relieved
lessons:
  - verify assumptions early
usable_topics:
  - difficult project
  - useful skill
  - teamwork
  - decision
```

When mapping topics, distinguish:

- natural fit;
- fit with minor adjustment;
- forced fit that should not be used.

Never claim a fixed number of stories covers a universal percentage of all
questions. Calculate coverage from the user's actual imported question bank.
